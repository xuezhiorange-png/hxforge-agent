## 2. Audit rule

The unit of admission is one case identity and its transitive evidence graph.
The following cannot be combined merely because their scalar values look
compatible:

```text
test fixture + release-demo value
TASK162 derived outlet + TASK160 inlet
TASK169 V06 Golden + TASK172 case role
generic material + case geometry
TASK026 snapshot + TASK171 physical support
```

A real case would need one canonical case/configuration identity and hash,
provenance, lifecycle, topology/path/support binding, and receipts whose
producer and source identities all point to that same case. A caller assertion,
array position, matching temperature/pressure, or a legacy result label is not
case authority.

hashes, stream/path/face identity, TASK171 topology, T/P, property authority
and snapshot, producer lifecycle, provenance, and canonical hashes. The
independent-review evidence records:

```ini
REAL_SHELL_INLET_STATE_INSTANCE_PRESENT=false
REAL_SHELL_OUTLET_STATE_INSTANCE_PRESENT=false
```

TASK160 is only a conditional inlet adapter. TASK162's derived outlet depends
on U, tube film, and shell film and is explicitly not admissible as the J_mu
source outlet. TASK032 is a single unlocated snapshot and is neither the
inlet, outlet, nor source mean. Therefore:

```ini

REAL_SHELL_OUTLET_STATE_BINDABLE=false
REAL_ENDPOINT_PAIR_BINDABLE=false
```
