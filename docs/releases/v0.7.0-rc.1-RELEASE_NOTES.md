# HXForge v0.7.0-rc.1 (Pre-release)

**Release type:** Experimental engineering pre-release (not manufacturing-grade design software).

## Summary

V07 delivers an **experimental automatic shell-and-tube design path** for a **declared water/water envelope**: user JSON engineering cases drive Task168–174 candidate generation, N1/N2/N4 mesh rating, live thermal/hydraulic postpass, three-scenario assumption-based K full-path nozzle co-optimization, and structured design reporting with strict acceptance gates.

## Capabilities in this pre-release

1. **User case input** — `hxforge.general-engineering-case.v2` JSON (duty, side conditions, pressure limits, discrete geometry constraints).
2. **Target duty constraints** — classification and constraint summaries use **`case.target_duty_w`** (330 kW is the sealed acceptance fixture input, not a hardcoded internal design target).
3. **Discrete structure generation** — Task168 manufacturable candidates + R27H experimental geometry ladder (shells 0.56/0.58/0.60 m with paired tube length / baffle spacing).
4. **Thermal rating** — Experimental engineering N1 screen and N1/N2/N4 mesh ladder with mesh evidence consistency checks.
5. **Hydraulics** — Internal live postpass Δp, authorized full-path calculator, component rows (`TUBE_DP_COMPONENTS`, `SHELL_DP_COMPONENTS`, Bell-Delaware internal shell Δp).
6. **Nozzle co-optimization** — `low_loss` / `mid_band` / `high_loss` assumption-K scenarios with velocity band 1–3 m/s.
7. **330 kW acceptance case** — Live E2E evidence on fixture `tests/fixtures/v07_live_acceptance_user_case.json`; frozen artifacts `tests/fixtures/V07_VERSION_DELIVERY_ACCEPTANCE.json` and `tests/fixtures/R27H_CANDIDATE_SPACE_EXTENSION.json` (best ranked candidate `5e78f6a8` is a **regression reference**, not a forced return value).

## Explicitly **not** verified or supported

- Arbitrary fluids, geometries, or exchanger types outside the declared experimental envelope.
- Code compliance, ASME/TEMA sign-off, mechanical design, fabrication drawings, or manufacturing approval.
- Engineering-validated local loss K values (assumption-based demo K only).
- Claim that **all** operating conditions pass because the **330 kW water/water ladder case** passed.
- PyPI publication, hosted deployment, or production sizing eligibility.

## Engineering disclaimer

**HXForge v0.7.0-rc.1 is experimental engineering calculation software.** Numeric feasibility under assumption-based full-path models **does not** constitute an approved heat exchanger design. Results require review by a qualified engineer before any manufacturing or procurement decision.
